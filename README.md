Java Network Socket Communication

Project Overview:
A fundamental implementation of Network Programming in Java using the TCP/IP protocol. This project demonstrates how to create a bidirectional communication channel between a Server and a Client using Sockets.

Technical:
Socket Programmin*: Utilizes `ServerSocket` and `Socket` classes from the `java.net` package to handle network connections.
Data Stream Handling: Implements `BufferedReader` and `PrintWriter` for efficient data exchange and message passing between entities.
Synchronous Communication: Demonstrates the classic request-response cycle where the server listens, accepts a connection, and responds to client input.
Port Management: Uses custom port configuration (`6789`) and localhost testing for network simulation.

Technologies Used
Language: Java
API: Java Networking API (`java.net`)
Core Concepts: TCP Sockets, I/O Streams, Client-Server Architecture.
